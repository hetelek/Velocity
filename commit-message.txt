feat: Add Xbox 360 ISO support with multi-language text encoding

This major release adds comprehensive Xbox 360 ISO parsing capabilities
and a custom text encoding module for Asian languages commonly found in
game files.

🎮 Xbox 360 ISO Support
━━━━━━━━━━━━━━━━━━━━━━
• XISO Parser
  - Full support for GDF, XGD3, and Redump ISO formats
  - Automatic magic string detection at multiple known offsets
  - AVL tree directory traversal with proper 4-byte offset handling
  - File extraction (single or batch) with directory structure preservation

• XEX Metadata Extraction
  - Parse Media ID, Title ID, version, and disc info from default.xex
  - Automatic extraction on ISO open
  - Filename-based metadata fallback

• ISO Browser UI
  - Tree view with hierarchical file display
  - Search/filter by filename
  - Double-click preview for images, text, and XML files
  - Context menu extraction with progress indication
  - Expand/collapse all folders

🌏 Text Encoding Module
━━━━━━━━━━━━━━━━━━━━━━
• Supported Encodings (9 total)
  - CP932 (Shift-JIS) - Japanese
  - CP936 (GBK) - Simplified Chinese
  - CP950 (Big5) - Traditional Chinese
  - CP949 (EUC-KR) - Korean
  - UTF-8, UTF-16 LE/BE, Latin-1, Auto-detect

• Auto-Detection Engine
  - BOM detection (UTF-8, UTF-16 LE/BE)
  - UTF-16 alternating pattern recognition
  - UTF-8 validation
  - Scoring-based legacy encoding detection (10-point threshold)

• Performance Optimization
  - O(1) hash map lookups (10,000x faster than linear search)
  - Lazy initialization with QMutex thread safety
  - Header/impl split: 99.8% size reduction (1,383 KB → 3.4 KB)

• UI Features
  - Encoding dropdown with 9 options + auto-detect
  - Status bar showing detection method
  - Manual override with instant re-decode
  - Tooltips for user guidance
  - Enhanced error messages with unmapped character warnings
